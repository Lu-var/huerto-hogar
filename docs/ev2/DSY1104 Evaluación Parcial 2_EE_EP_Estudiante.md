## Instrucciones Generales para el/la Estudiante

Cada evaluación parcial será una parte del examen transversal. En la Evaluación Parcial 2, el equipo continuará trabajando en el desarrollo del caso semestral integrando un nuevo framework de frontend (React) a la plantilla HTML/CSS/JS provista. Deberán crear y estructurar componentes, implementar navegación, formularios y validación, además de analizar, documentar y desarrollar pruebas unitarias con Jasmine y Karma.

El trabajo se desarrolla en **Taller de Alto Cómputo** en equipos de máximo 3 personas, pero la evaluación del encargo y la presentación será **individual**.

---

## Instrucciones Específicas de la Evaluación

### Situación Evaluativa 1: Entrega por encargo

1. **Incorporar frontend basado en JS / React:**
   * Comprobar el uso de un framework moderno (React) bien estructurado.
   * Gestionar correctamente propiedades (*props*) y estados (*state*).
   * Asegurar diseño responsivo mediante **Bootstrap**.
   * Explicar y documentar el proceso de desarrollo y la integración responsiva.

2. **Crear pruebas unitarias:**
   * Desarrollar pruebas para los componentes frontend abarcando diferentes casos de uso, lógica, comportamiento y manipulación del DOM mediante **Jasmine y Karma**.

3. **Implementar proceso de testeo:**
   * Configurar herramientas de testeo, redactar pruebas unitarias, usar mocks y realizar análisis de cobertura/resultados.

#### Documentos Requeridos y Entregables:
* Enlace GitHub público del proyecto frontend actualizado.
* Proyecto frontend actualizado comprimido.
* Documento ERS (Especificación de Requisitos de Software) versión final.
* Documento de cobertura de testing.

---

### Situación Evaluativa 2: Presentación

Durante la presentación individual, cada estudiante debe:
1. Exponer cómo se diseñó el proyecto utilizando el framework JS frontend.
2. Mostrar el proceso de desarrollo de componentes React, manejo de props, estados y diseño responsivo con Bootstrap.
3. Demostrar la creación y ejecución de pruebas unitarias con Jasmine y Karma.
4. Explicar el proceso de testeo unitario (configuración, mocks, cobertura y resultados).

## Pauta de Evaluación (Rúbrica)

### Criterios de Niveles de Logro
* **Muy buen desempeño (100%):** Destacado, cumple con todos los aspectos evaluados.
* **Buen desempeño (80%):** Alto desempeño con pequeñas omisiones o errores menores.
* **Desempeño aceptable (60%):** Logra elementos básicos pero presenta omisiones o errores.
* **Desempeño incipiente (30%):** Importantes omisiones o errores que no permiten evidenciar los elementos básicos.
* **Desempeño no logrado (0%):** Ausencia o incorrecto desempeño.
